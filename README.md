# CueRelay

当前版本：1.2.0。CueRelay 是一个第三方 Windows 定时提示词与屏幕操作助手，已加入窗口尺寸恢复、F8 虚拟捕获、慢速执行、小窗口滚动布局、任务原始信息查看和按标题自动切换左侧对话。

这是一个 Windows 本地桌面工具，用来把准备好的提示词定时粘贴到目标 AI 应用输入框，并点击发送按钮或按 Enter 发送。

## 启动

双击同目录下的 `启动_CueRelay.cmd`。电脑上只需要有 Python 3.10+，不需要安装第三方库。

## 第一次使用

1. 打开 Codex，并进入要发送提示词的会话；建议先把窗口调整到你希望任务执行时使用的正常大小和位置。
2. 启动本工具，点击“虚拟捕获输入框”，确认提示后把鼠标移到 Codex 输入框内，按一次 F8。不会实际点击输入框；如果键盘功能键需要组合使用，请按 `Fn+F8`。
3. 如果发送方式选择“点击已捕获的发送按钮”，点击“虚拟捕获发送按钮”，把鼠标移到语音按钮所在位置，按一次 F8。不会触发语音；输入文字后该位置应切换为发送按钮。
4. 如果任务需要固定对话，在“目标对话标题”填写 Codex 左侧显示的对话标题或唯一关键词；然后在“目标窗口与校准”中点击“虚拟捕获搜索按钮”，把鼠标移到左侧放大镜/搜索按钮，按一次 F8。不会实际点击。
5. 输入任务名称和提示词内容，选择单次、每天或按间隔执行。
6. 点击“保存到计划”。可以先用“仅粘贴测试”确认位置，再在右侧点击“立即运行”。

默认按“点击已捕获的发送按钮”执行；如果不想校准发送按钮，可以选择“按 Enter 发送”。

## 运行行为

- 工具默认绝对置顶；执行自动化时会暂时隐藏自身，避免挡住 Codex，完成后恢复置顶。
- 默认会在执行前恢复捕获时的目标窗口位置和大小；如果窗口状态是最大化，也会保持最大化。可在界面中关闭该选项。
- 输入位置会按窗口变化调整，发送位置同时保存精确坐标和右下边缘偏移，以适配输入框展开和按钮切换。
- 单击计划列表只会在下方只读区域显示任务原始 JSON，不会把任务载入编辑器；“查看原始信息”可打开更大的查看窗口，其中包含精确的 `next_run` 时间、目标对话标题和校准信息。
- 任务填写了“目标对话标题”后，执行前会点击已捕获的左侧搜索按钮，粘贴标题并按 Enter 切换对话，再执行输入和发送。留空则保持当前对话。
- 默认每个步骤等待 1.5 秒，可选择 0.8、1.5、2.5 或 4 秒。
- 主界面带垂直滚动，并在窗口较窄时自动改为上下布局；不需要完全放大窗口才能使用。
- 执行前会再次查找 Codex / ChatGPT 窗口并确认它仍是前台窗口；找不到或失去焦点时会停止，不会向其它程序盲目输入。
- 若关闭“恢复捕获时窗口位置和大小”，不会把已最大化的 ChatGPT 窗口恢复成普通窗口；开启后则按你校准时的窗口状态恢复。
- 旧任务没有目标对话标题时不会增加切换动作；若旧任务要使用新功能，请点击“编辑选中”，填写标题后重新更新计划。
- 程序会尽量恢复执行前的文本剪贴板内容。
- 任务和设置保存在 `cuerelay_data.json`，运行日志在 `cuerelay.log`，未处理错误在 `cuerelay_crash.log`。
- 关闭窗口会询问是否退出；退出后定时任务不再运行。系统休眠期间无法执行，唤醒后会按当前任务状态继续。

## 注意

这是基于 Windows 鼠标与键盘事件的本地自动化。发送前请确认目标应用已登录、会话正确，且“全权限”等高风险设置符合你的预期。CueRelay 与 OpenAI、ChatGPT、Codex 或其它目标应用没有隶属、赞助或官方认可关系。长提示词建议选择“按 Enter 发送”，或在实际提示词长度下重新检查发送按钮位置。
