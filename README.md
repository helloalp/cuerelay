# CueRelay

当前版本：2.0.0

Windows 本地定时提示词工具：把准备好的提示词按计划交给目标 AI 应用，并在发送前后验证结果。

不需要安装任何第三方 Python 库，只要有 Python 3.10+。

## 启动

双击 `启动_CueRelay.cmd`。

命令行：

```
python cuerelay.py           启动界面
python cuerelay.py --check   运行无界面自检（识别算法、调度、数据迁移）
python cuerelay.py --version 显示版本
```

## 界面

左侧三个视图：任务、日志、设置。

- **任务**：左侧列表按「启用状态 → 下次执行时间」排序，顶部可搜索。右键任意任务可以暂停/启用、立即运行、复制一份或删除，不需要先载入编辑器。右侧编辑区修改后点「保存」，或「保存并运行」立即验证一次。
- **日志**：按级别筛选，带时间戳，可直接打开日志文件。
- **设置**：目标应用关键词、识别与校准、执行间隔与补执行窗口、主题与置顶、数据位置。

主题有浅色与深色两套，标题栏会跟随主题一起切换（Windows 10 1809 及以上）。所有尺寸按系统 DPI 缩放，125%/150%/200% 缩放下文字不会被位图拉伸。

## 2.0 做了什么

1.9 及更早的版本依赖手动校准坐标：先隐藏窗口，把鼠标移到输入框，按 F8 记录位置，再对发送按钮做一次。窗口一旦缩放、DPI 变化、输入框因为多行内容变高，坐标就会失效，而且失败时没有任何提示。

2.0 把定位方式换成了实时界面识别：

- **输入框**：在目标窗口的客户区截图上寻找一块横向贯通、上下各有一条方向相反长边缘的独立面板。窗口移动、缩放、换主题都不影响。
- **发送按钮**：在识别出的输入框右下角寻找对比度最高、接近正方形的紧凑色块。输入框因为内容变高时，按钮位置会被重新计算。
- **对话搜索框**：在左侧栏顶部寻找同样的面板结构，用于自动切换对话。
- **结果验证**：粘贴后比较输入框区域的像素变化，发送后比较输入框是否被清空。没变化就重试一次，仍然失败会明确报错，而不是静默失败。

识别不到时会退回到上一次识别缓存的位置，再退回到手动锚点。任何一步都不会比旧版本更差。

## 第一次使用

1. 打开目标应用（默认关键词 `codex, chatgpt, openai`，可在设置里改），进入要发送提示词的会话。
2. 启动 CueRelay，进入「设置」。
3. 点击「自动识别并预览」。窗口会暂时隐藏，随后弹出识别结果：截图上会用方框标出输入框、发送按钮和对话搜索框。确认无误后点「保存」。
4. 回到「任务」，填写名称与提示词，选择计划方式，点「保存」。
5. 需要立刻验证时点「保存并运行」。

如果预览里框错了，点「重新识别」；如果某个位置始终识别不到，可以在「识别与校准」里用「手动指定」按 F8 记录一次坐标作为兜底。

## 识别与校准

- 执行时优先实时识别。设置里的「执行时重新识别界面」关闭后，才会直接使用保存的位置。
- 「校验粘贴结果」「校验发送结果」默认开启。关闭后执行更快，但失败时不会报错。
- 「对话切换失败时中止」默认开启。关闭后，找不到左侧搜索框时会直接在当前对话发送。
- 自动识别失败常见原因：目标窗口被别的窗口遮挡、窗口处于最小化、目标应用还没渲染完成。识别会重试，但遮挡是截不到内容的，执行前请让目标窗口可见。

## 运行行为

- 窗口默认置顶，可在标题栏或设置里关闭。
- 执行时会暂时隐藏自身，避免挡住目标窗口，完成后恢复。
- 默认在执行前恢复校准时的窗口位置和大小，可在设置里关闭。
- 执行前会确认目标窗口是前台窗口，不是就停止，不会向其它程序输入。
- 粘贴与发送之间会重新识别一次输入框，以适配多行内容导致的输入框变高。
- 程序会尽量恢复执行前的文本剪贴板，并把鼠标移回执行前的位置。
- 同一时刻只允许一个任务驱动鼠标键盘，避免多个任务抢占窗口。
- 步骤间隔只影响固定等待，识别与校验使用自适应轮询，不受该值限制。
- 错过执行时间超过「补执行窗口」就跳过本次；单次任务会标记为已过期，重复任务会推进到下一次计划。
- 任务与设置保存在 `cuerelay_data.json`，运行日志在 `cuerelay.log`，未处理错误在 `cuerelay_crash.log`。
- 从 1.x 升级时，旧文件会自动迁移，并保留一份 `cuerelay_data.v1.json` 备份。旧版本的手动锚点会按窗口坐标继续生效。

## 数据

任务字段：名称、提示词、目标对话、计划方式（单次 / 每天 / 间隔）、发送方式（点击发送 / Enter 发送）、启用状态。

日志页可按级别筛选，并直接打开日志文件。

## 开发

```
cuerelay.py                入口，只做路径与参数处理
cuerelay_app/winapi.py     Win32 封装（窗口枚举、截图、鼠标键盘、剪贴板、DPI）
cuerelay_app/imaging.py    位图容器与 PNG 预览编码
cuerelay_app/vision.py     识别算法（面板、发送按钮、搜索框、变化检测）
cuerelay_app/locator.py    识别 → 缓存 → 锚点 的三级定位
cuerelay_app/automation.py 单次执行流程与结果校验
cuerelay_app/scheduler.py  调度线程与窗口互斥
cuerelay_app/store.py      数据持久化与版本迁移
cuerelay_app/ui/           主题、自绘控件、主窗口、识别预览
tools/make_icon.py         生成 assets/cuerelay.ico（改动图标后重新运行）
```

`python cuerelay.py --check` 的 11 项自检覆盖识别算法（含整窗布局）、矩形缩放、调度推进、旧数据迁移与预览图编码，不需要打开窗口。

## 注意

这是基于 Windows 鼠标与键盘事件的本地自动化。发送前请确认目标应用已登录、会话正确。CueRelay 与 OpenAI、ChatGPT、Codex 或其它目标应用没有隶属、赞助或官方认可关系。
